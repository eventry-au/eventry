Overview

Getting started

Eventry is Australia's sports events directory — a single place where athletes can discover, filter, and register for sporting events across the country. Listing your event is free and takes about 5 minutes.

What you'll need before you start
✓
Your organisation name and contact details
✓
Event name, date, and location
✓
A short description of the event
✓
Details of each discipline/category (distances, prices)
✓
Your registration URL (your existing booking page)
✓
Your organisation logo (PNG or JPG)
ℹ️
Your registration link stays yours. Eventry doesn't process registrations — we send athletes directly to your existing registration page (e.g. EntryCentral, EventBrite, your own site). You keep full control of your bookings.

Step 3 of 4

Disciplines & distances

This is where Eventry differs from other directories. Instead of one event = one listing, you can add every race category, distance, and format your event offers. Each is called a discipline.

💡
What counts as a discipline? Each separately-priced or separately-distanced category. For example: a running event with a 5km, 10km, 21km, and 42km has 4 disciplines. A triathlon festival with a Sprint, Olympic, and Kids Tri has 3 disciplines.

Adding your first discipline

1
Select the sport type
Choose from the dropdown — Running, Cycling, Triathlon, Open Water Swimming, etc. The distance fields will automatically change to match the sport.
2
Enter the distance(s)
Each sport shows the relevant distance fields. Select the unit (m, km, or miles) using the toggle buttons next to each field.
3
Enter the entry fee
Enter the price in AUD. If the discipline is free to enter, tick the "Free entry" checkbox instead.
4
Add a category name
Give this discipline a name athletes will recognise — e.g. "Sprint Triathlon", "42km Marathon", "Kids 5km Dash".
5
Add more disciplines
Click "Add another discipline" to repeat for each category your event offers. There's no limit.

Distances & units

Every distance field has a three-way unit toggle. Select the unit that matches how your event is advertised.

UnitWhen to useHow it displays on site
m (metres)Swim legs, short obstacle courses, sprint distances under 1km750m, 400m, 1500m
km (kilometres)Standard Australian distances — most road, trail, and cycle events42km, 100km, 5km
milesEvents specifically advertised in miles — 100-miler ultras, US-origin races100 miles (160.9km)
💡
Miles tip: Only use miles if your event is genuinely advertised in miles (e.g. a 100 Mile race). If your event is 160km, enter it as 160km — not 99.4 miles. When miles are selected, the km equivalent is automatically shown in brackets on the event listing.
Advanced

Custom "Other" events

For unique multi-sport events that don't fit a standard format — adventure races, expedition events, custom relays — select "Other / Custom" as the sport type. This unlocks a fully custom leg builder.

⭐
What qualifies as "Other"? Any event with a unique combination of activities — kayak + run + swim + cycle, horse ride + hike + abseil, or any sequence that doesn't match the standard Triathlon or Duathlon formats.

How to build a custom event

1
Select "Other / Custom" from the sport dropdown
The standard distance fields will be replaced by the custom leg builder.
2
Name your event type
Give it a descriptive name athletes will understand — e.g. "Bush to Beach Adventure Race" or "Red Centre Multi-Sport Challenge"
3
Add legs in race order
Click "Add a leg" for each stage. Select the activity type and enter the distance with unit. Add as many legs as your race has — there's no limit.
4
Use "Custom" for unique activities
If your activity isn't in the dropdown (e.g. "Abseil", "Sand Boarding", "Cave Crawl"), select "Custom" from the activity dropdown and type it in.

Worked example — Red Centre Adventure Race

Here's how you'd enter a unique 8-leg adventure race:

How to fill in the form
// Event type name
Event type: Red Centre Adventure Race

// Legs in race order
Leg 1: Kayak — 8 km
Leg 2: Run — 12 km
Leg 3: Cycle — 45 km
Leg 4: Swim — 1500 m
Leg 5: Hike — 8 km
Leg 6: Abseil (Custom) — 80 m
Leg 7: Cycle — 30 km
Leg 8: Run — 5 km

// How it displays on the site
Kayak 8km → Run 12km → Cycle 45km → Swim 1500m → Hike 8km → Abseil 80m → Cycle 30km → Run 5km
✅
Each leg has its own unit toggle. So you can mix metres (for the swim), kilometres (for the run and cycle), and even miles for legs specifically advertised that way — all within the same event.

Multiple categories within a custom event

If your adventure race has an Elite category and a Teams category with different distances, add them as separate disciplines — click "Add another discipline", select "Other / Custom" again, and build the legs for the second category.

Help

Frequently asked questions

Can I list multiple events at once? ▼
Yes — submit each event separately through the form. There's no limit on how many events you can list. If you have a large calendar of events, email us at hello@eventry.au and we can discuss a bulk upload process.
What's the difference between an event and a discipline? ▼
An event is the overarching race day or festival — e.g. "Noosa Triathlon Festival". A discipline is each separately-priced category within that event — e.g. Sprint Tri ($155), Olympic Tri ($195), Kids Tri ($45). One event can have unlimited disciplines.
Do I need to use Eventry's registration system? ▼
No — Eventry doesn't process registrations. You provide your existing registration URL (EntryCentral, EventBrite, your own website, etc.) and we link directly to it. Athletes register through your normal process.
My event has different prices for early bird vs full price — which do I enter? ▼
Enter the standard (full) entry price. You can mention early bird pricing in the Additional Notes field. We recommend keeping the price current — if early bird has closed, update it to the current price by emailing hello@eventry.au.
Can I list an event that happens every year? ▼
Yes — list this year's event now. When next year's date is confirmed, submit a new listing for the upcoming edition. We'll archive the old one automatically after the event date passes.
What if my event spans multiple locations? ▼
Enter the start location as the primary location. You can describe the full course route in the event description or Additional Notes field.
My event is in miles — should I convert to km? ▼
No — if your event is genuinely advertised in miles (e.g. a 100 Mile ultramarathon), select "miles" as the unit. Eventry will automatically show the km equivalent in brackets. Only use miles if that's how the race is actually promoted.
How do I get a Featured listing? ▼
During our launch phase, Featured listings are available at no cost to select organisers. Email hello@eventry.au to discuss featuring your event. Online payment for Featured listings is coming soon.
I submitted but haven't heard back — what should I do? ▼
Check your spam folder first. If you still haven't received a confirmation after 24 hours, email hello@eventry.au with your event name and we'll look into it.
