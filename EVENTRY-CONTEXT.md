# 1. Purpose & Concept

Eventry (eventry.au) is Australia's sports events directory — a side project rooted in the experience of finishing a sporting event and wondering "what's next?" The name blends "Event" and "Entry." The platform serves both participants (discovering and entering events) and organisers (free listings with optional paid features). Monetisation is on hold pending legal advice regarding work conditions.

# 9. Key Learnings & Principles

- **Column alignment discipline:** Removing a sheet column requires a placeholder in Apps Script.
- **Cross-session continuity via EVENTRY-CONTEXT.md:** Regenerate at end of every session.
- **Batch changes before uploading:** Adriaan prefers to batch code changes before GitHub upload.
- **Partner data discipline:** Keep records at pending until outreach is complete.
- **Duplicate the sheet tab** before structural changes.
- **no-cors masks all server failures:** Always verify via sheet or Apps Script Executions log.
- **Installable vs simple triggers:** onEdit named literally = simple trigger, can't send email.
- **GitHub large file paste (web editor) silently produces 0-byte files** — use upload/replace for files >500 lines.
- **Google Sheets Date object auto-conversion:** Always use instanceof Date guard before .toString() on date cells.
- **Auto go-live email fires on any approval** — leave org_email blank when adding events manually to suppress it.
- **Manually added events should have org_email blank** — prevents unwanted go-live emails to organisers you haven't contacted yet.
- **Cycle racing events are NOT members-only** — day AusCycling licences available at events. List them with a note.
- **Club recurring races (crits, HEZ, ITT series)** are valid Eventry listings — athletes use them as training benchmarks between races.
- **MVCC "crit track" = Taree Criterium Track** — confirmed venue name.
- **Pace Athletic owns Blue Mountains Running Co** — same business (Trasa Holdings Pty Ltd). Approach via Pace Athletic head office only.
- **Always add events via xlsx file** — tab-separated causes column alignment errors.
